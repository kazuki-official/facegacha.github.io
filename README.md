# プライバシーポリシー

本プライバシーポリシーは、モバイル端末向けアプリ「Face Gacha」および Kazuki Kitano が運営する関連サービス（以下、総称して「本アプリ」といいます）に適用されます。Kazuki Kitano を以下「サービス提供者」といいます。

## 情報の収集と利用

本アプリは、お客様がダウンロードおよび利用する際に情報を収集します。収集する情報には、以下のようなものが含まれる場合があります。

- 本アプリの利用時間（起動・復帰の回数、開いていた時間、各画面の滞在時間）
- アプリ内のアクティビティ（ガチャを引いた、リアクションを送った、写真を投稿した、などの操作の記録。詳細は「行動ログ（利用状況の分析）」をご覧ください）
- 端末の機種、OS のバージョン、アプリのバージョン、言語、おおよその地域（国・都道府県程度）
- お客様がアップロードした画像（お客様ご自身の顔が写った写真を含みます。詳細は「顔データの取り扱い」をご覧ください）
- お客様が設定したプロフィールアイコン（顔が写っている場合があります）
- お客様が送受信したメッセージ

## 顔データの取り扱い

本アプリは、お題に沿ってお客様ご自身の顔が写った写真を投稿し、フレンドのガチャに排出されることを楽しむサービスです。本項では、顔が写った写真（以下「顔データ」といいます）の収集、利用、開示、共有、および保持について説明します。

### 収集する顔データ

- お客様がお題への投稿として、カメラで撮影またはフォトライブラリから選択してアップロードした、お客様ご自身の顔が写った写真
- お客様がプロフィールアイコンとして設定した画像（顔が写っている場合）

顔データは、お客様が明示的に投稿または設定の操作を行った場合にのみ収集します。カメラやフォトライブラリへのアクセスは、お客様が iOS の権限ダイアログで許可した場合に限り行い、お客様が選択した写真以外を本アプリが取得することはありません。

本アプリは、顔の特徴点、顔の幾何学的形状、顔認識用のテンプレートなどの生体情報を抽出、生成、または保存することはありません。顔認証、本人確認、属性推定（年齢・性別・感情など）、および顔による個人の識別や追跡は行いません。

### 顔データの利用目的

顔データは、以下の目的にのみ利用します。

- お客様が投稿した写真を、お客様のフレンドのガチャのラインナップとして表示すること
- ガチャで写真を引いたフレンドが、その写真をコレクションとして閲覧できるようにすること
- フレンドがお客様の投稿に対してリアクションやコメントを行い、お客様がそれを確認できるようにすること
- プロフィールアイコンを、お客様のフレンドおよびチャットの相手に表示すること
- 本アプリの正常な動作、不具合の調査、および不正利用の防止

顔データを広告の配信、機械学習モデルの学習、または上記以外の目的に利用することはありません。利用目的を追加する場合は、本ポリシーを更新し、法令で必要とされる場合にはお客様の同意を改めて取得します。

### 顔データの開示と共有

- **フレンドへの共有**: お客様が投稿した写真は、本アプリ内でお客様とフレンドになっている利用者のガチャに排出され、引いたフレンドのコレクションに表示されます。獲得したフレンドは、そのカードを本アプリ内のフレンドとのチャットで共有することがあります。お客様の写真がフレンド以外の利用者に排出されることはありません。
- **処理の委託先**: 顔データは、Google LLC が提供する Firebase（Cloud Storage for Firebase および Cloud Firestore）に保存されます。Google はサービス提供者の処理委託先として、サービス提供者の指示に基づいてのみデータを処理し、独自の目的で顔データを利用することはありません。
- **第三者への販売・提供**: サービス提供者は、顔データを第三者に販売、貸与、または提供することはありません。また、分析・広告などの第三者 SDK に顔データを送信することもありません。
- **法令に基づく開示**: 法令、裁判所の命令、または行政機関の正当な要請に基づき開示が義務付けられる場合に限り、必要な範囲で開示することがあります。

### 顔データの保持と削除

- 投稿した写真は、お客様が本アプリ内でその投稿を削除するまで保持します。投稿を削除すると、写真の実体、ならびにフレンドのコレクションおよびガチャのラインナップに含まれる当該写真の記録は、サービス提供者のサーバーから削除されます。
- プロフィールアイコンは、お客様が新しい画像に差し替えるか、アカウントを削除するまで保持します。差し替えた場合、以前の画像は上書きにより削除されます。
- アカウントは、本アプリのプロフィール画面にある「アカウントを削除」から、いつでもお客様ご自身で削除できます。削除を実行すると、投稿した写真、プロフィールアイコン、フレンド関係、トーク、ガチャの獲得記録、およびアカウント情報は、サービス提供者のサーバーから直ちに削除されます。本アプリを利用できない場合は、kazuki.official1003@gmail.com までご連絡いただければ、サービス提供者が請求を受領してから 30 日以内に削除します。いずれの場合も、法令により保持が義務付けられるデータを除きます。
- フレンドの端末に一時的にキャッシュされた画像は、当該フレンドの端末上で本アプリがキャッシュを破棄するか、本アプリがアンインストールされた時点で削除されます。
- バックアップに含まれる顔データは、通常のバックアップのローテーションに従い、削除から最長 30 日以内に消去されます。

## 行動ログ（利用状況の分析）

サービス提供者は、本アプリの改善のために、Google LLC が提供する Firebase Analytics（Google アナリティクス）を使ってお客様の利用状況を記録します。

### 記録する内容

- 起動・復帰の回数と、開いていた時間
- 表示した画面（ガチャ・コレクション・トーク・プロフィール）と、その滞在時間
- 操作の記録。ガチャを引いた、ラインナップを更新した、カードに絵文字やひとことを送った、トークで送信した（テキストかカードかの区別と、返信かどうか）、お題の写真を投稿した（お題の種類と、選んでから投稿するまでの時間）、お題を引き直した、ガチャの回数がふえた、など
- 端末の機種、OS のバージョン、アプリのバージョン、言語、おおよその地域（国・都道府県程度。IP アドレスそのものは保存されません）
- Firebase が端末ごとに発行する識別子（アプリのインストール単位で発行され、アンインストールするとリセットされます）

### 利用目的

- どの機能がどれだけ使われているかを把握し、本アプリの使いやすさを改善すること
- 不具合や、操作の途中で止まってしまう箇所を見つけること

行動ログを広告の配信やお客様個人の追跡に利用することはありません。また、他社のサービスと横断してお客様を追跡することもありません。

### 共有と保存先

行動ログは Google LLC の Firebase Analytics に送信・保存されます。Google はサービス提供者の処理委託先として、サービス提供者の指示に基づいてデータを処理します。Google の取り扱いについては、Google のプライバシーポリシー（https://policies.google.com/privacy）をご覧ください。行動ログを広告事業者やその他の第三者に販売・提供することはありません。

### 保持期間とオプトアウト

行動ログは、収集から最長 24 か月間保持します（「データ保持方針」の「自動的に収集されたデータ」に該当します）。本アプリをアンインストールすると、端末ごとの識別子がリセットされ、以降の記録は行われません。すでに送信されたログの削除をご希望の場合は、kazuki.official1003@gmail.com までご連絡ください。
