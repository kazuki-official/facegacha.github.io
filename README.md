- アプリ内のアクティビティ

お客様は、サービス提供者が保有するお客様の個人データについて、アクセス、訂正、または削除を請求することができます。これらの権利を行使する場合、または同意に基づく処理について同意を撤回する場合は、kazuki.official1003@gmail.com までサービス提供者にご連絡ください。

サービス提供者が本アプリおよびサービスを改善するために、集計および匿名化されたデータのみが外部サービスへ定期的に送信されます。サービス提供者は、本プライバシーポリシーに記載した方法で、お客様の情報を第三者と共有する場合があります。

個人データの削除請求、同意の撤回、またはその他の権利の行使については、kazuki.official1003@gmail.com までサービス提供者にご連絡ください。

## データ保持方針

サービス提供者は、記載された目的に対する必要性に基づいて個人データを保持します。

- お客様が提供したデータ：本アプリの利用期間中およびその後 12 か月間保持します。ただし、法令によりそれより長い保持が求められる場合を除きます。
- 自動的に収集されたデータ：収集から最長 24 か月間保持します。ただし、法令遵守のためにそれより長い保持が必要な場合を除きます。
- 集計および匿名化されたデータ：お客様個人を識別できなくなっているため、無期限に保持します。
- 法令遵守に必要なデータ：適用される法令で求められる期間、保持します。

お客様は、法令上の保持義務に反しない範囲で、個人データの削除を請求することができます。本アプリを通じて提供したデータの削除をご希望の場合は、kazuki.official1003@gmail.com までご連絡ください。なお、お客様が提供したデータの一部は、本アプリが正常に機能するために必要となる場合があります。
